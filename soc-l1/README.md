# SOC Level 1

File lộ trình của nhóm nằm ngay tại `learning-path.json`. Các module liên quan nằm bên cạnh, mỗi module có `vi/`, `en/`, `media/`.

Viết bài theo nhu cầu của bạn, không cần theo thứ tự học. `topics` trong Markdown phân loại bài lên website; `steps[].article` trong file lộ trình chọn ID bài và thứ tự học. Một ID có thể dùng trong nhiều path.

SOC L1 đã có đủ khung bài. Các nhóm chưa có đề cương đầy đủ được giữ draft; tác giả bổ sung khi bắt đầu viết. Xem `CONTRIBUTING.md` ở gốc repo và `CONTENT.md` của website.
